# 数据分析与报表

## ADDED Requirements

### Requirement: 设备利用率分析

系统应提供设备利用率分析功能，包括在线率、故障率、MTBF（平均故障间隔时间）和MTTR（平均恢复时间）。

#### Scenario: 获取设备在线率
- **WHEN** 用户请求设备在线率统计
- **THEN** 系统应返回：
  - 总设备数量
  - 在线设备数量
  - 离线设备数量
  - 在线率百分比

#### Scenario: 获取设备故障率
- **WHEN** 用户请求设备故障率统计
- **THEN** 系统应返回：
  - 故障设备数量
  - 故障率百分比
  - 故障类型分布
  - 统计时间范围

#### Scenario: 计算MTBF
- **WHEN** 用户请求MTBF指标
- **THEN** 系统应基于历史故障数据计算平均故障间隔时间
- **AND** 单位为小时或天

#### Scenario: 计算MTTR
- **WHEN** 用户请求MTTR指标
- **THEN** 系统应基于故障恢复数据计算平均恢复时间
- **AND** 单位为小时或分钟

### Requirement: 网络带宽分析

系统应提供网络带宽使用情况分析，包括带宽使用趋势和峰值统计。

#### Scenario: 获取带宽使用趋势
- **WHEN** 用户请求带宽趋势分析
- **THEN** 系统应返回指定时间段的带宽使用数据
- **AND** 数据应按小时/天/月聚合
- **AND** 应包括上行和下行带宽

#### Scenario: 获取带宽峰值
- **WHEN** 用户请求带宽峰值统计
- **THEN** 系统应返回：
  - 历史最高带宽
  - 平均带宽
  - 峰值发生时间
  - 与平均带宽的偏差

#### Scenario: 按节点分析带宽
- **WHEN** 用户请求按边缘节点分组的带宽统计
- **THEN** 系统应返回每个节点的：
  - 当前带宽使用
  - 峰值带宽
  - 带宽使用趋势

### Requirement: 存储容量分析

系统应提供存储容量分析功能，包括存储使用趋势和增长率统计。

#### Scenario: 获取存储使用趋势
- **WHEN** 用户请求存储使用趋势
- **THEN** 系统应返回存储容量随时间的变化
- **AND** 数据应按天/周/月聚合
- **AND** 应包括热/温/冷存储分别统计

#### Scenario: 获取存储增长率
- **WHEN** 用户请求存储增长率
- **THEN** 系统应计算：
  - 日增长率
  - 周增长率
  - 月增长率
  - 预计存储耗尽时间

#### Scenario: 获取存储分布
- **WHEN** 用户请求存储分布统计
- **THEN** 系统应返回：
  - 各区域存储使用情况
  - 各边缘节点存储使用情况
  - 存储类型分布（录像/日志/其他）

### Requirement: 故障统计分析

系统应提供故障统计分析功能，包括故障类型分布和故障趋势。

#### Scenario: 获取故障类型分布
- **WHEN** 用户请求故障类型分布
- **THEN** 系统应返回各类故障的数量和占比
- **AND** 故障类型应包括：网络故障、设备故障、存储故障、CDN故障等

#### Scenario: 获取故障趋势
- **WHEN** 用户请求故障趋势分析
- **THEN** 系统应返回故障数量随时间的变化
- **AND** 数据应支持按天/周/月查看
- **AND** 应区分已解决和未解决故障

#### Scenario: 获取故障热力图
- **WHEN** 用户请求故障热力图
- **THEN** 系统应在地图上展示故障分布
- **AND** 使用颜色深浅表示故障密度
- **AND** 点击区域可查看详情

### Requirement: 数据分析API

系统应提供数据分析API供前端调用。

#### Scenario: 请求设备利用率数据
- **WHEN** 前端发送 GET /api/v1/analytics/device-usage
- **THEN** 系统应返回设备利用率统计数据
- **AND** 支持按时间范围过滤

#### Scenario: 请求网络带宽数据
- **WHEN** 前端发送 GET /api/v1/analytics/bandwidth
- **THEN** 系统应返回网络带宽统计数据
- **AND** 支持按时间范围和节点过滤

#### Scenario: 请求存储数据
- **WHEN** 前端发送 GET /api/v1/analytics/storage
- **THEN** 系统应返回存储容量统计数据
- **AND** 支持按存储类型和区域过滤

#### Scenario: 请求故障统计数据
- **WHEN** 前端发送 GET /api/v1/analytics/failures
- **THEN** 系统应返回故障统计数据
- **AND** 支持按故障类型和时间范围过滤

### Requirement: 报表生成

系统应支持生成并导出数据分析报表。

#### Scenario: 生成Excel报表
- **WHEN** 用户请求导出Excel报表
- **THEN** 系统应生成.xlsx格式文件
- **AND** 文件应包含请求的分析数据
- **AND** 应包含报表标题、生成时间、统计周期

#### Scenario: 选择报表时间范围
- **WHEN** 用户设置报表时间范围
- **THEN** 系统应基于该范围生成报表
- **AND** 支持快速选择：今天、昨天、本周、本月、自定义

#### Scenario: 选择报表类型
- **WHEN** 用户选择报表类型
- **THEN** 系统应生成相应类型的报表
- **AND** 支持类型：设备利用率、网络带宽、存储容量、故障统计

#### Scenario: 添加报表自定义列
- **WHEN** 用户自定义报表列
- **THEN** 系统应仅导出选定的列
- **AND** 保存用户偏好供下次使用

### Requirement: 报表订阅

系统应支持报表订阅功能，定时发送报表邮件。

#### Scenario: 创建报表订阅
- **WHEN** 用户创建报表订阅
- **THEN** 系统应保存订阅配置
- **AND** 配置应包括：报表类型、频率、收件人、时间范围

#### Scenario: 定时发送报表
- **WHEN** 到达报表发送时间
- **THEN** 系统应自动生成报表
- **AND** 系统应通过邮件发送报表
- **AND** 系统应记录发送状态

#### Scenario: 管理报表订阅
- **WHEN** 用户查看报表订阅列表
- **THEN** 系统应显示所有订阅
- **AND** 显示：订阅名称、频率、下次发送时间、状态
- **AND** 支持启用/禁用、编辑、删除订阅

### Requirement: 图表展示

系统应在前端提供图表展示数据分析结果。

#### Scenario: 折线图展示趋势
- **WHEN** 用户查看趋势数据
- **THEN** 前端应使用折线图展示
- **AND** 支持鼠标悬停查看数据点详情
- **AND** 支持图例显示/隐藏数据系列

#### Scenario: 柱状图展示分布
- **WHEN** 用户查看分布数据
- **THEN** 前端应使用柱状图展示
- **AND** 应显示数值标签
- **AND** 支持按数量排序

#### Scenario: 饼图展示占比
- **WHEN** 用户查看占比数据
- **THEN** 前端应使用饼图展示
- **AND** 应显示百分比标签
- **AND** 支持点击扇区查看详情

#### Scenario: 热力图展示地理分布
- **WHEN** 用户查看地理分布数据
- **THEN** 前端应使用热力图展示
- **AND** 颜色深浅表示数值大小
- **AND** 支持缩放和平移

### Requirement: 实时数据更新

系统应支持实时更新数据分析结果。

#### Scenario: 实时更新仪表盘
- **WHEN** 系统指标发生变化
- **THEN** 仪表盘数据应自动刷新
- **AND** 刷新间隔应可配置（默认30秒）

#### Scenario: WebSocket推送数据更新
- **WHEN** 用户打开分析页面
- **THEN** 系统应建立WebSocket连接
- **AND** 数据变化时通过WebSocket推送更新
- **AND** 用户离开页面时关闭连接
