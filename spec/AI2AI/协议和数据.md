## 数据库设计

### cameras（摄像头表）**[修改]**
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |

| edge_node_id | BIGINT | FK → edge_nodes(id) | 关联边缘节点 |
| protocol | ENUM | NOT NULL | RTSP/ONVIF/GB28181/HTTP/RTMP |
| connection_url | VARCHAR(500) | NOT NULL | 连接地址 |
| username | VARCHAR(100) | | 认证用户名 |
| password | VARCHAR(200) | | 认证密码 |
| resolution | VARCHAR(50) | | 分辨率 |
| frame_rate | INT | | 帧率 |
| bitrate | INT | | 码率 |
| status | ENUM | NOT NULL | ONLINE/OFFLINE/CONNECTING/ERROR/**MAINTENANCE/PENDING_ALLOCATION** |
| last_active_time | DATETIME | | 最后活跃时间 |
| is_enabled | BOOLEAN | DEFAULT TRUE | 是否启用 |
| **is_deleted** | **BOOLEAN** | **DEFAULT FALSE** | **软删除标记 [新增]** |
| **deleted_at** | **DATETIME** | | **软删除时间 [新增]** |
| created_at | DATETIME | | 创建时间 |
| updated_at | DATETIME | | 更新时间 |

**说明**: Camera 实体使用了 Hibernate `@Where(clause = "is_deleted = false")` 过滤器，默认所有查询会自动排除已软删除的记录（与 Recording 实体相同的模式）。需访问已删除记录的操作（恢复/强制删除/清理任务）通过 nativeQuery 绕过该过滤器。

### camera_failover_events（故障转移事件表）**[新增]**
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGSERIAL | PK | 主键 |
| source_edge_node_id | BIGINT | NOT NULL | 源(离线)节点ID |
| total_count | INT | NOT NULL | 待迁移摄像头总数 |

| failed_count | INT | DEFAULT 0 | 失败数(进入待分配池) |
| trigger_type | VARCHAR(20) | NOT NULL | AUTO/MANUAL |
| status | VARCHAR(20) | NOT NULL | IN_PROGRESS/COMPLETED/PARTIAL/FAILED |
| error_message | TEXT | | 错误信息 |
| created_at | TIMESTAMP | NOT NULL, DEFAULT NOW() | 创建时间 |
| completed_at | TIMESTAMP | | 完成时间 |

**关联子表**:
- `failover_event_target_nodes`: (event_id, target_edge_node_id) — 本次迁移涉及的目标节点
- `failover_event_cameras`: (event_id, camera_id) — 本次迁移涉及的摄像头

## 枚举定义

### CameraStatus
```
ONLINE           # 在线
OFFLINE          # 离线
CONNECTING       # 连接中
ERROR            # 错误
MAINTENANCE      # 维护中

```

### CameraFailoverEvent.TriggerType
```
AUTO             # 自动触发（节点离线）
MANUAL           # 手动触发（API调用）
```

### CameraFailoverEvent.Status
```
IN_PROGRESS      # 进行中
COMPLETED        # 全部成功
PARTIAL          # 部分失败
FAILED           # 全部失败
```
