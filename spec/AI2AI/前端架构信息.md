# 前端架构信息

## 项目概述

多地区监控平台 (Multi-region Monitoring Platform, MMP) 前端，基于 React 18 + Ant Design 5.x + Tailwind CSS 构建，采用工业风设计系统（Industrial Command Center）。

## 技术栈

| 类别 | 技术 | 版本 |
|------|------|------|
| 框架 | React | 18.x |
| UI 库 | Ant Design | 5.x |
| 样式方案 | Tailwind CSS + CSS Variables (三层架构) | 3.x |
| 路由 | React Router | 6.x |
| 状态管理 | React Context + Hooks | - |
| HTTP 客户端 | Axios | 1.x |
| 视频播放 | HLS.js, WebRTC | - |
| 构建工具 | Create React App | 5.x |

## 三层样式架构（Phase 2 引入）

```
Layer 1: Design Tokens (CSS Variables)
├── 文件: theme.css
├── 内容: 颜色/间距/阴影/字体/动画关键帧/Login专用变量
└── 规范: 所有变量在此定义一次，禁止在其他文件重复

Layer 2: Component Classes (Tailwind @layer components)
├── 文件: index.css (@layer components), VideoWall.css, Login.css, Header.css, Sidebar.css
├── 内容: .industrial-card / .video-card / .industrial-stat-card 等可复用组合类
└── 规范: 使用 @apply 封装，避免内联 style

Layer 3: Utility Classes (Tailwind in JSX)
├── 文件: 各页面组件的 className
├── 内容: className="bg-background-card text-text-primary flex items-center"
└── 规范: 原子化工具类直接在 JSX 中使用
     内联 style={} 仅用于运行时动态计算值
```

**禁止事项**:
- ❌ 在页面组件中使用 `<style>` 标签
- ❌ 在 `theme.css` 外部重复定义 `@keyframes`
- ❌ 在 `App.css` 中滥用 `!important`（除非绝对必要且注释说明）
- ❌ 硬编码颜色值（必须使用 CSS Variables）

## 🆕 AI 分析模块

### aiApi.ts（AI API 客户端）

TypeScript 服务层，封装所有 AI 分析 REST API 调用（Axios + 类型定义）：

```typescript
// 接口类型定义
interface PassengerStats { cameraId, startTime, endTime, enterCount, exitCount, insideCount, maxInsideCount }
interface BehaviorEvent { id, cameraId, eventType, level, positionData, description, eventTime, status }
interface VehicleRecord { id, cameraId, plateNumber, plateColor, confidence, isWhitelisted, detectTime }
interface WhitelistEntry { id, plateNumber, plateColor, ownerName, description, enabled, createdAt }

// API 函数
getPassengerStats(params)          // GET /api/v1/ai/stats/passenger
getRealtimePassengerStats(id)      // GET /api/v1/ai/stats/passenger/realtime/{cameraId}
getBehaviorAlerts(params)          // GET /api/v1/ai/alerts/behavior
updateBehaviorAlertStatus(id)      // PUT /api/v1/ai/alerts/behavior/{id}/status
getVehicleRecords(params)          // GET /api/v1/ai/vehicles/records
getWhitelist()                     // GET /api/v1/ai/vehicles/whitelist
addWhitelistEntry(data)            // POST /api/v1/ai/vehicles/whitelist
updateWhitelistEntry(id, data)     // PUT /api/v1/ai/vehicles/whitelist/{id}
deleteWhitelistEntry(id)           // DELETE /api/v1/ai/vehicles/whitelist/{id}
```

### 🆕 AI 页面

#### AiPassengerDashboard.tsx（客流看板）
- **实时客流**：5 秒轮询当前 `insideCount`，Statistic 卡片展示
- **摄像头选择**：Select 下拉选择摄像头
- **历史统计**：DatePicker.RangePicker 选择时间范围，Table 展示客流统计数据
- **数据流**：① ai-passenger-stats → Kafka → AiPassengerStatsConsumer → MySQL + Redis → AiAnalysisController → 前端

#### AiBehaviorAlertCenter.tsx（行为告警中心）
- **告警列表**：Table 展示告警事件，Tag 显示 eventType，Badge 显示 level
- **筛选**：按 eventType（LOITERING/INTRUSION/GATHERING/FALL）和 status（ACTIVE/RESOLVED）过滤
- **处理操作**：点击"处理"按钮更新告警状态为 RESOLVED
- **数据流**：② ai-behavior-events → Kafka → AiBehaviorEventConsumer → MySQL + Alert 系统 → AiAnalysisController → 前端

#### AiLicensePlateManagement.tsx（车牌管理）
- **识别记录**：搜索车牌号码，Table 展示识别记录
- **白名单管理**：CRUD 弹窗操作（Modal），支持添加/编辑/删除白名单条目
- **数据流**：③ ai-vehicle-records → Kafka → AiVehicleRecordConsumer → MySQL → AiAnalysisController → 前端

## 主题切换增强（Phase 3）

- **默认行为**: 首次访问自动检测系统偏好（`prefers-color-scheme`）
- **实时跟随**: 未手动设置过时，监听系统偏好变化并自动切换
- **手动优先**: 用户手动选择后存 localStorage，不再跟随系统

## Tailwind 最佳实践规范

### 推荐用法

```jsx
// ✅ 静态布局 → Tailwind 工具类
<div className="flex items-center gap-4 px-5 py-3 bg-background-card rounded-lg">

// ✅ 条件性暗色 → data-theme + CSS Variable 或 dark: 前缀
<div className="dark:text-white">

// ✅ 响应式断点
<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4">
```

### 避免用法

```jsx
// ❌ 不要用 Tailwind 替代动态值
<div style={{ animationDelay: `${index * 0.1}s` }}>  // 保留 inline

// ❌ 不要在 className 中硬编码颜色值
<div className="text-[#00d4ff]">  // 改为 text-accent 或自定义颜色映射

// ❌ 不要过度嵌套工具类
<div className="flex flex-col flex-row ...">  // 保持语义清晰
```
