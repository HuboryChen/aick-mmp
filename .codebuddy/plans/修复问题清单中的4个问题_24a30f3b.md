## 问题概述

用户报告了4个问题：

1. API Key列表查询失败，出现懒加载异常
2. 系统应用新增后数据未落库
3. 侧边栏菜单需移除个人中心入口
4. 个人中心密码展示和API Key状态操作问题

## 核心问题

- **问题1和2**：JPA懒加载导致的 `no Session` 异常，影响API Key查询和SystemApp数据落库
- **问题3**：前端侧边栏菜单冗余
- **问题4**：前端状态值与后端枚举不匹配，密码组件位置不当

## 技术方案

### 问题1：API Key懒加载异常修复（后端）

**根因**：`ApiKey.java` 中 `systemApp` 字段使用 `FetchType.LAZY`，在 `toDTO()` 方法访问时Session已关闭

**方案**：将 `@ManyToOne(fetch = FetchType.LAZY)` 改为 `@ManyToOne(fetch = FetchType.EAGER)`

**修改文件**：

- `backend/aick-mmp-shared/src/main/java/com/aick/mmp/shared/model/ApiKey.java` 第49行

### 问题2：SystemApp数据落库问题

**根因**：与问题1相同，懒加载异常可能导致事务回滚。问题1解决后自动解决。

### 问题3：侧边栏菜单修改（前端）

**方案**：从 `Sidebar.js` 的 `menuItems` 数组中移除个人中心菜单项

**修改文件**：

- `frontend/src/components/Sidebar.js` 第80-84行

### 问题4：个人中心UI和API Key状态修复（前端）

**子问题4a - 密码展示**：

- 将 `ProfilePasswordReset` 组件从Tabs外部移入Tabs内部，作为一个独立Tab
- 按需求仅在用户主动切换到密码Tab时显示

**子问题4b - API Key状态**：

- **根因**：前端使用 `ACTIVE/DISABLED`，后端枚举定义为 `ENABLED/DISABLED`
- 前端传参 `{"status":"ACTIVE"}` 无法被后端反序列化为 `ApiKeyStatus` 枚举
- **方案**：修改前端状态值为 `ENABLED/DISABLED`

**修改文件**：

- `frontend/src/pages/UserProfile.js` 第279-288行（状态值修改）
- `frontend/src/pages/UserProfile.js` 第520-582行（密码组件移入Tabs）
- `frontend/src/pages/ApiKeyManagement.js` 第157-170行（状态值修改）
